/*
--------------------------------------------------------------------------
Clone the board

Get source card location

Get source card copy

Remove source card from cloned board

Determine if drag location is a list or a card
- Get drag location
- Get drag object

Move the card to the new location

Update the position

TODO: Send updated card with new position to API

--------------------------------------------------------------------------
Edge Cases
--------------------------------------------------------------------------

1. No lists on board
   - Nothing happens. This dragging logic is bound to having at least one list present.

2. List is empty

3. There is only one item on the list
   - Handled by card drag logic.
   - Check if the drag location is near the end of the list or at the start.
   - This logic works regardless of how many cards are in the list.
   - If there are no cards, only the list drag object applies (see case 2).
   - List logic is mostly the same.


--------------------------------------------------------------------------
Drag Check Logic
--------------------------------------------------------------------------

onDragEnd()
- If drag location is the same object:
    - Cancel.

- If drag location is out of bounds (not a list or card):
    - Cancel (null).


applyDrag()
-------------------------------
Clone board
↓
Find source
↓
Remove source
↓
Determine target type
    ├── List
    └── Card
↓
Insert at correct location
↓
Update position
↓
Return updated board
--------------------------------

- If drag location is a list:
    - If list is empty:
        - Insert card at position 0.

    - Else if drag is above target:
        - Insert card at the beginning of the list.

    - Else:
        - Insert card at the end of the list.

    - Return.


- If drag location is a card:
    - If drag is above target:

        - If dragging at the start of the list:
            - Insert before the first card.

        - Else:
            - Normal drag operation between two cards.


    - Else drag below target:

        - If dragging at the end of the list:
            - Insert after the last card.

        - Else:
            - Normal drag operation between two cards.

*/
